# 主变差流计算器 (Transformer Differential Current Calculator)

电力系统继电保护校验工具 —— 用于变压器差动保护(主变差动)的定值校验与相量分析。

纯 HTML + JavaScript 实现,无任何外部依赖,浏览器直接打开即可使用。

## 功能特性

- **绕组结构**:支持两绕组 (Yd11) 与三绕组 (YYd11) 变压器
- **输入参数**:额定容量 S、比率制动系数 K、各侧额定电压、CT 变比、三相电流幅值与相角
- **平衡系数**:基于二次额定电流 I₂n 自动计算各侧平衡系数 K_bal
- **转角方式**(V1.3 新增,可选):
  - **高压侧转角**(默认):对星形侧进行 Y→Δ 相位补偿,三角形侧保持不变
  - **低压侧转角**:星形侧减零序 + 三角形侧 Δ→Y(RCS-978 方式),供不同厂家/接线选用
  - 切换转角方式后,各侧标签、图 2 标题与相量图内容即时同步更新
- **差动判据**:逐相计算差动电流 Id 与制动电流 Ir,按比率制动特性 Id > K·Ir 判断动作
- **对称分量**:基于原始二次电流计算正序、负序、零序分量(零序反映接地故障特征)
- **功率分析**:以高压侧 A 相电压为基准计算各侧 P / Q 及功率流向
- **角度约定**:支持"超前角为正 / 滞后角为正"两种约定切换,物理相量不变
- **相量图可视化**:Canvas 绘制原始二次电流相量图与平衡补偿 + 转角变换后相量图
- **公式数学排版**:页面内「计算说明」中全部公式(平衡系数、转角变换、差动判据、对称分量等)以排版公式呈现,便于阅读核对

## 使用方法

直接使用浏览器打开 `主变差流计算器V1.4.html` 即可,无需安装、无需服务器。

1. 选择绕组结构(两绕组 / 三绕组)
2. 选择转角方式(高压侧转角 / 低压侧转角)
3. 输入额定容量 S(MVA)与比率制动系数 K
4. 填写各侧额定电压、CT 变比(支持 `600/5`、`600:5`、`120` 三种写法)
5. 输入各侧三相电流幅值(A 或 mA)与相角(°)
6. 点击「计算」查看差动判据、对称分量、功率及相量图
7. 可点击「应用预设」快速载入示例数据校验

> 提示:计算结果以额定电流 Ie 的倍数显示差动电流与制动电流,便于与保护定值直接比对。

## 计算原理简述

- 转角方式:
  - 平衡系数:K_bal(高) = 1;K_bal(中/低) = I₂n(高) / I₂n(中/低),其中 I₂n = S / (√3·U) / nCT
  - **高压侧转角**(星侧 Y→Δ):I′ₐ = (Iₐ − I_b)/√3,I′ᵦ = (I_b − I_c)/√3,I′꜀ = (I_c − Iₐ)/√3
  - **低压侧转角**(RCS-978):星侧减零序 I′ᵢ = Iᵢ − I₀;三角形侧 Δ→Y:I′ₐ = (Iₐ − I_c)/√3 I′ᵦ = (I_b − Iₐ)/√3 I′꜀ = (I_c − I_b)/√3
- 差动电流:Id = |Σ 平衡后各侧电流|;制动电流:Ir = (Σ|Iᵢ|)/2(固定除以 2,与侧数无关)
- 比率制动判据:Id > K·Ir 时该相动作
- 对称分量:a = 1∠120°,正序 I₁ = (Iₐ + a·I_b + a²·I_c)/3,负序 I₂ = (Iₐ + a²·I_b + a·I_c)/3,零序 I₀ = (Iₐ + I_b + I_c)/3

详细说明可展开页面内「计算说明」查看。
