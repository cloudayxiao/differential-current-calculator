# 主变差流计算器 (Transformer Differential Current Calculator)

电力系统继电保护校验工具 —— 用于变压器差动保护(主变差动)的定值校验与相量分析。

纯 HTML + JavaScript 实现,无任何外部依赖,浏览器直接打开即可使用。

## 功能特性

- **绕组结构**:支持两绕组 (Yd11) 与三绕组 (YYd11) 变压器
- **输入参数**:额定容量 S、比率制动系数 K、各侧额定电压、CT 变比、三相电流幅值与相角
- **平衡系数**:基于二次额定电流 I₂n 自动计算各侧平衡系数 K_bal
- **Y-Δ 变换**:对星形侧自动进行 Y-Δ 相位补偿(三角形侧保持不变)
- **差动判据**:逐相计算差动电流 Id 与制动电流 Ir,按比率制动特性 Id > K·Ir 判断动作
- **对称分量**:基于原始二次电流计算正序、负序、零序分量(零序反映接地故障特征)
- **功率分析**:以高压侧 A 相电压为基准计算各侧 P / Q 及功率流向
- **角度约定**:支持"超前角为正 / 滞后角为正"两种约定切换,物理相量不变
- **相量图可视化**:Canvas 绘制原始二次电流相量图与平衡补偿 + Y-Δ 变换后相量图
- **数据持久化**:输入数据自动保存至浏览器 localStorage,刷新不丢失

## 使用方法

直接使用浏览器打开 `主变差流计算器V1.2.html` 即可,无需安装、无需服务器。

1. 选择绕组结构(两绕组 / 三绕组)
2. 输入额定容量 S (MVA) 与比率制动系数 K
3. 填写各侧额定电压、CT 变比(支持 `600/5`、`600:5`、`120` 三种写法)
4. 输入各侧三相电流幅值(A 或 mA)与相角(°)
5. 点击「计算」查看差动判据、对称分量、功率及相量图
6. 可点击「应用预设」快速载入示例数据校验

> 提示:计算结果以额定电流 Ie 的倍数显示差动电流与制动电流,便于与保护定值直接比对。

## 计算原理简述

- 平衡系数:K_bal(高) = 1;K_bal(中/低) = I₂n(高) / I₂n(中/低),其中 I₂n = S / (√3·U) / nCT
- Y-Δ 变换:I′ₐ = (Iₐ − I_b)/√3,I′ᵦ = (I_b − I_c)/√3,I′꜀ = (I_c − Iₐ)/√3(仅星形侧)
- 差动电流:Id = |Σ 平衡后各侧电流|;制动电流:Ir = 各侧幅值平均值
- 比率制动判据:Id > K·Ir 时该相动作
- 对称分量:a = 1∠120°,正序 I₁ = (Iₐ + a·I_b + a²·I_c)/3,负序 I₂ = (Iₐ + a²·I_b + a·I_c)/3,零序 I₀ = (Iₐ + I_b + I_c)/3

详细说明可展开页面内「计算说明」查看。
