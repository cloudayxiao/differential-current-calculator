# 主变差流计算器 (Transformer Differential Current Calculator)

电力系统继电保护校验工具 —— 用于变压器差动保护(主变差动)的定值校验与相量分析。

纯 HTML + JavaScript 实现,无任何外部依赖,浏览器直接打开即可使用。

## 功能特性

- **绕组结构**:支持两绕组 (Yd11) 与三绕组 (YYd11) 变压器
- **输入参数**:额定容量 S、差动最小动作电流（Iop.min / Icdqd，按转角方式自动切换）、各侧额定电压、CT 变比、三相电流幅值与相角
- **平衡系数**:基于二次额定电流 I₂n 自动计算各侧平衡系数 K_bal
- **转角方式**(V1.3 新增,可选):
  - **高压侧转角**(默认,与 PST1200U 系列一致):对星形侧进行 Y→Δ 相位补偿,三角形侧保持不变
  - **低压侧转角**:星形侧减零序 + 三角形侧 Δ→Y(RCS-978 方式),供不同厂家/接线选用
  - 切换转角方式后,各侧标签、图 2 标题与相量图内容即时同步更新
- **差动判据**(V2.0 新增,随转角方式绑定厂家判据):
  - 高压侧转角 → **PST1200U 稳态比率差动三折线**(拐点 0.8Ie/3Ie,斜率 0.5/0.7 装置固定,整定 Iop.min)
  - 低压侧转角 → **PCS-978 稳态比率差动**(低值 + 高值判据,Kbl=0.5 装置固定,整定 Icdqd)
  - 动作门槛 Id.set 按所选厂家判据计算,结果表逐相给出 Id / Ir / Id.set 及动作结论
- **对称分量**:基于原始二次电流计算正序、负序、零序分量(零序反映接地故障特征)
- **功率分析**:以高压侧 A 相电压为基准计算各侧 P / Q 及功率流向
- **角度约定**:支持"超前角为正 / 滞后角为正"两种约定切换,物理相量不变
- **相量图可视化**:Canvas 绘制原始二次电流相量图与平衡补偿 + 转角变换后相量图
- **动作特性曲线**(V2.1 新增):图 3 以 Id–Ir 曲线可视化差动判据 —— 高压侧转角绘制 PST1200U 三折线,低压侧转角绘制 PCS978 低值+高值两组曲线,灰色阴影标示动作区,并按计算结果逐相标注运行点(圆点颜色按相别黄/绿/红,实心圆=动作、空心圆=不动作),拐点与斜率标注于图中对应位置
- **差动速断保护**(V2.2 新增):输入差动速断电流定值 Icdsd(单位 Ie,缺省 6Ie),图 3 以红色水平虚线标绘速断整定线;速断不经二次谐波/五次谐波/CT 断线闭锁、瞬时动作,优先于比率差动保护
- **公式数学排版**:页面内「计算说明」中全部公式(平衡系数、转角变换、差动判据、对称分量等)以排版公式呈现,便于阅读核对

## 使用方法

直接使用浏览器打开 `主变差流计算器V2.2.1.html` 即可,无需安装、无需服务器。

1. 选择绕组结构(两绕组 / 三绕组)
2. 选择转角方式(高压侧转角 / 低压侧转角)——同时决定所采用的厂家差动判据
3. 输入额定容量 S(MVA)、差动最小动作电流 Iop.min(高压侧转角)/ 差动启动电流 Icdqd(低压侧转角)与差动速断电流 Icdsd
4. 填写各侧额定电压、CT 变比(支持 `600/5`、`600:5`、`120` 三种写法)
5. 输入各侧三相电流幅值(A 或 mA)与相角(°)
6. 点击「计算」查看差动判据、对称分量、功率、相量图及动作特性曲线
7. 可点击「应用预设」快速载入示例数据校验

> 提示:计算结果以额定电流 Ie 的倍数显示差动电流、制动电流与动作门槛 Id.set,便于与保护定值直接比对。

## 计算原理简述

- 转角方式:
  - 平衡系数:K_bal(高) = 1;K_bal(中/低) = I₂n(高) / I₂n(中/低),其中 I₂n = S / (√3·U) / nCT
  - **高压侧转角**(星侧 Y→Δ):I′ₐ = (Iₐ − I_b)/√3,I′ᵦ = (I_b − I_c)/√3,I′꜀ = (I_c − Iₐ)/√3
  - **低压侧转角**(RCS-978):星侧减零序 I′ᵢ = Iᵢ − I₀;三角形侧 Δ→Y:I′ₐ = (Iₐ − I_c)/√3 I′ᵦ = (I_b − Iₐ)/√3 I′꜀ = (I_c − I_b)/√3
- 差动电流:Id = |Σ 平衡后各侧电流|;制动电流:Ir = (Σ|Iᵢ|)/2(固定除以 2,与侧数无关)
- 比率制动判据(V2.0,随转角方式选择):
  - **高压侧转角(PST1200U 三折线)**:Ir<0.8Ie → Id≥Iop.min;0.8Ie≤Ir<3Ie → Id≥Iop.min+0.5(Ir−0.8Ie);Ir≥3Ie → Id≥Iop.min+0.5·2.2Ie+0.7(Ir−3Ie)
  - **低压侧转角(PCS-978)**:低值 Ir≤0.5Ie → Id>Icdqd+0.2Ir;0.5Ie<Ir≤6Ie → Id>Icdqd+0.5(Ir−0.5Ie)+0.1Ie;Ir>6Ie → Id>Icdqd+0.5·5.5Ie+0.75(Ir−6Ie)+0.1Ie;高值(Ir>0.8Ie)Id>1.2Ie+0.6(Ir−0.8Ie);动作门槛取低值与高值之较小者
- 差动速断判据(V2.2 新增):Id ≥ Icdsd → 差动速断动作(不经二次谐波/五次谐波/CT 断线闭锁,瞬时动作)
- 对称分量:a = 1∠120°,正序 I₁ = (Iₐ + a·I_b + a²·I_c)/3,负序 I₂ = (Iₐ + a²·I_b + a·I_c)/3,零序 I₀ = (Iₐ + I_b + I_c)/3

详细说明可展开页面内「计算说明」查看。
