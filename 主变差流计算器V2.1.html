计算说明（点击展开）

1. 角度基准与相角约定：始终以高压侧 A 相电压为 0° 基准。默认约定超前角为正（电流超前电压时相角为正）；可切换为滞后角为正（电流滞后电压时相角为正）。切换约定时，输入角度按 θ′ = (360° − θ) mod 360° 换算，同一电流对应的物理相量保持不变。相量图遵循数学惯例：0° 沿水平向右，角度以逆时针为正。

2. 额定二次电流与幅值平衡（平衡系数）：各侧二次额定电流按额定容量、额定电压与 CT（电流互感器）变比折算：

I2n = S√3 · U · nCT

式中 U 为该侧额定线电压（kV），nCT 为 CT 变比。以高压侧为基准（Kbal(H) = 1）：

Kbal(s) = I2n(H)I2n(s)

式中 s 为任一侧，H 为高压侧。

幅值平衡（平衡补偿）：Ibal = I2 · Kbal（仅幅值缩放，相位不变）。

3. 相位校正（转角）：为消除 Y/Δ 接线引起的相位差，各侧电流须经相位校正后再进入差动计算，两种方式可选：

① 高压侧转角（星形侧进行 Y→Δ 变换，三角形侧不变）：国内绝大多数装置采用该方式（如国电南自 PST1200U/PST-1202、四方 CSC-326、长园深瑞 PRS-778、许继 WBH-801、南瑞继保 RCS-985 等）。

I′a = Ia − Ib√3　I′b = Ib − Ic√3　I′c = Ic − Ia√3

② 低压侧转角（角转星方式：星形侧减去零序电流，三角形侧进行 Δ→Y 变换；以南瑞继保 RCS-978 / 国电南瑞 PCS-978 系列为代表）：

星形侧：I′i = Ii − I0，其中 I0 = Ia + Ib + Ic3。

三角形侧：I′a = Ia − Ic√3　I′b = Ib − Ia√3　I′c = Ic − Ib√3。

两种方式在正常运行（无内部故障）时补偿后差动电流一致（数学等价），Id ≈ 0；仅在存在不平衡电流或零序分量时，补偿后电流相量的表达形式不同。两种方式对应的差动动作判据不同（见第 5 条：高压侧转角按 PST1200U 三折线、低压侧转角按 PCS978 低值/高值判据）。经幅值平衡与相位校正后的电流统称为补偿后电流，后续差动计算均基于补偿后电流。

4. 差动电流与制动电流：

Id = |Σ I′s|　　Ir = Σ |I′s|2

式中 I′s 为第 s 侧补偿后电流的幅值。制动电流取各侧补偿后电流幅值之和的一半（固定除以 2，与侧数无关），与国电南自 PST1200U、南瑞继保 PCS978 等主流装置的比率制动形式一致。

5. 差动动作判据（随转角方式选择厂家判据）：

① 高压侧转角（PST1200U 三折线）——按 PST1200U 稳态比率差动判据，拐点与斜率均为装置固定值，仅整定最小动作电流 Iop.min（输入值，单位 Ie）：

Ir < 0.8Ie　：　Id ≥ Iop.min
0.8Ie ≤ Ir < 3Ie　：　Id ≥ Iop.min + 0.5 · (Ir − 0.8Ie)
Ir ≥ 3Ie　：　Id ≥ Iop.min + 0.5 · 2.2Ie + 0.7 · (Ir − 3Ie)

拐点 1 取 0.8Ie、拐点 2 取 3Ie；斜率 1 取 0.5、斜率 2 取 0.7（装置固定，无需整定）。

② 低压侧转角（PCS978 稳态比率差动）——按 PCS-978 稳态比率差动判据（低值 + 高值），启动电流 Icdqd 为输入值（单位 Ie），比率制动系数 Kbl = 0.5 装置固定：

低值判据：

Ir ≤ 0.5Ie　：　Id > Icdqd + 0.2 · Ir
0.5Ie < Ir ≤ 6Ie　：　Id > Icdqd + 0.5 · (Ir − 0.5Ie) + 0.1Ie
Ir > 6Ie　：　Id > Icdqd + 0.5 · 5.5Ie + 0.75 · (Ir − 6Ie) + 0.1Ie

高值判据（Ir > 0.8Ie 时）：

Id > 1.2Ie + 0.6 · (Ir − 0.8Ie)

动作门槛取低值与高值之较小者（任一满足即动作）。结果表中 Id、Ir、Id.set 均以额定电流 Ie（= 高压侧二次额定电流 I2n(H)）的倍数显示。

③ 动作特性曲线（图 3）：按所选厂家判据实时绘制 Id–Ir 曲线，横轴为制动电流 Ir、纵轴为差动电流 Id，均以 Ie 为单位；量程随计算结果动态调整，且两轴刻度比例一致。高压侧转角绘制 PST1200U 三折线；低压侧转角绘制 PCS978 低值（三段）+ 高值两组曲线（高值以虚线区分）。判据曲线上方以灰色阴影标示差动动作区，曲线下方为制动（不动作）区；拐点（0.8Ie/3Ie 或 0.5Ie/6Ie）与各段斜率（K1=0.5/K2=0.7，或 K=0.2/0.5/0.75、高值 K=0.6）标注于图中对应位置。计算所得的 A/B/C 三相运行点 (Ir, Id) 以相别颜色（黄 A / 绿 B / 红 C）圆点标入图中，实心圆 = 动作、空心圆 = 不动作，与结果表动作结论一致；运行点落入阴影区即表示该相差动保护动作。

6. 功率：一次电流 I1 = I2 · nCT；相电压 Vph = U · 1000√3（U 为额定线电压，kV；Vph 为相电压，V）。电压相角以高压侧 A 相电压为 0° 基准：高压侧、中压侧（星形）A/B/C 相分别为 0°、−120°、120°；低压侧（三角形）A/B/C 相分别为 30°、−90°、150°。每相复功率 S = V · I∗，P = Re(S)，Q = Im(S)；P > 0 表示功率流入变压器，P < 0 表示功率流出。

7. 对称分量：基于原始二次电流（未经幅值平衡与相位校正）计算，其中 a = 1∠120° 为旋转因子：

I1 = Ia + a · Ib + a² · Ic3　I2 = Ia + a² · Ib + a · Ic3　I0 = Ia + Ib + Ic3

正序分量对应平衡的三相系统；负序分量反映相序不对称；零序分量反映三相共模分量，是接地故障的特征量。

8. 图例（颜色与线型）：相量图（图 1、图 2）中 H/M/L 分别表示高压侧/中压侧/低压侧。相色：A 相 黄色、B 相 绿色、C 相 红色。线型：H 实线、M 虚线、L 点划线（线宽 2.5 px）；差动电流以黑色虚线绘制（线宽 3 px，仅图 2）。动作特性曲线（图 3）图例：实线/虚线分别表示判据与高值（低压侧转角时），● 黄点 = A 相、● 绿点 = B 相、● 红点 = C 相运行点，实心圆 = 动作、空心圆 = 不动作。
