1. 角度基准：始终以高压侧 A 相电压为 0°。默认约定超前角为正（电流超前电压角度为正）；可切换为滞后角为正，切换时输入角度按 θ′ = (360 − θ) % 360 转换，物理相量不变。相量图遵循数学约定：0° 沿水平向右，角度以逆时针为正。

2. 额定二次电流与平衡系数：各侧额定电流按额定容量折算，再除以 CT 变比。

I2n = S√3 · U · nCT

以高压侧为基准（K_bal(高) = 1）：

Kbal(侧) = I2n(高)I2n(侧)

平衡后的二次电流：Ibal = I2 · Kbal（幅值缩放，相位不变）。

3. 转角补偿：为消除 Y/Δ 接线引起的相位差，对电流做相位补偿后进入差动计算。两种方式供选择：

① 高压侧转角（星形侧 Y→Δ，三角形侧不变）：

I′a = Ia − Ib√3　I′b = Ib − Ic√3　I′c = Ic − Ia√3

② 低压侧转角（RCS-978 方式：星形侧减零序，三角形侧 Δ→Y）：

星形侧：I′i = Ii − I0，　I0 = Ia + Ib + Ic3
三角形侧：I′a = Ia − Ic√3　I′b = Ib − Ia√3　I′c = Ic − Ib√3

两种方式在平衡运行（无内部故障）时差动电流一致（数学等价），Id ≈ 0；仅在存在不平衡或零序分量时，补偿后相量表现形式不同，但差动判据结果一致。

4. 差动电流与制动电流：

Id = |Σ 各侧平衡补偿后电流|　　Ir = Σ |I′s|n（n 为参与侧数）

比率制动判据：Id > K · Ir 时该相动作。表中 Id / Ir / K·Ir 均以额定电流 Ie（= 高压侧二次额定电流 I2n(高)）的倍数显示。

5. 功率：一次电流 I1 = I2 · nCT；相电压 Vph = U · 1000√3；电压相角：高压侧/中压侧为 0°/−120°/120°（星形），低压侧为 30°/−90°/150°（三角形）。每相 S = V · I*，P = Re(S)，Q = Im(S)；P > 0 表示流入变压器，P < 0 表示流出。

6. 对称分量：基于原始二次电流（未经平衡补偿与转角变换）计算，其中 a = 1∠120°：

I1 = Ia + a · Ib + a² · Ic3　I2 = Ia + a² · Ib + a · Ic3　I0 = Ia + Ib + Ic3

正序代表平衡三相系统，负序表示相序相反的不平衡，零序反映三相共模分量（接地故障特征）。

7. 颜色/线型：A 相 金黄色、B 相 绿色、C 相 橙红色；H 实线、M 虚线、L 点划线（均为 2.5px）；差动电流为黑色虚线（3px，仅图 2）。相量图中 H/M/L 分别表示高压侧/中压侧/低压侧。
